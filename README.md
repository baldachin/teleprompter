# 提词器 Teleprompter

面向 iPhone 的滚动提词器。纯静态 Web App（PWA），零依赖、免构建、离线可用。

## 功能

- **一页两态**：准备台 → 提词态 → 完成态，不再需要「编辑页 / 提词页」来回跳。
- **提词中实时调参**：右上角「设置」升起抽屉，字号、行距、边距、语速、主题、镜像即时生效，**不中断提词**。
- **三套配色预设**：黑底白字 / 白底黑字 / 黑底黄字。
- **两种速度单位**：默认「字 / 分钟」（随字号联动换算 px/s），可切「像素 / 秒」精调。
- **当前段高亮**：正在读的那一段用强调色标出。
- **手动定位**：上下拖动任意跳转，松手自动续播；轻点显隐控制条。
- **完成态**：重播 / 回到准备台 / 下一条脚本。
- **iPhone 适配**：竖屏锁定、全屏无地址栏、状态栏沉浸、安全区适配、禁双击缩放、375px 窄屏无横向溢出。
- **常亮与离线**：Wake Lock 防熄屏、Service Worker 断网可用（需 https 环境）。

## 使用

### iPhone（推荐）

1. 用 **Safari** 打开站点 https 地址。
2. 底部「分享」→ **添加到主屏幕**。
3. 从主屏图标启动，即为全屏提词模式。

### 本地开发

```bash
node serve.js 5173     # 启动本地服务并打印局域网地址
```

手机与电脑同一 Wi-Fi 时，用 iPhone Safari 访问打印出的地址即可（局域网 http 下常亮与离线不生效）。

### 截图验证

```powershell
pwsh -File scripts/capture.ps1   # 生成 390×844 移动端截图到 artifacts/
```

## 目录结构

```
index.html            单页两态结构（准备台 / 提词态 / 抽屉 / 浮层）
assets/app.js         全部逻辑
assets/styles.css     全部样式与三套主题变量
assets/icon-*.png     应用图标
manifest.webmanifest  PWA 清单
sw.js                 离线缓存
serve.js              本地静态服务器
scripts/              截图与发布脚本
docs/                 需求、对照与部署说明
```

## 说明

- 数据（脚本、设置、脚本库）仅保存在浏览器 `localStorage`，不上传任何服务器。
- 需要摄像头录制能力暂未实现（见 `docs/REQUIREMENTS.md` 的后续计划）。
