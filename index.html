    使用说明

    • iPhone 全屏：Safari 打开本页 → 分享 → 添加到主屏幕 → 从图标启动，即无地址栏全屏提词。
    • 提词中调参：点右上角「设置」升起抽屉，字号、边距、语速、主题即时生效，不会打断提词。
    • 手动定位：在文字区上下拖动可任意跳转，松手后自动继续滚动；轻点则隐藏控制条。
    • 三套配色：黑底白字（暗光）、白底黑字（室内亮光）、黑底黄字（强光下最醒目）。
    • 语速：默认按「字 / 分钟」计，随字号联动换算为像素速度；也可切换为「像素 / 秒」精调。
    • 离线可用：首次打开后即可断网使用，脚本与设置保存在本机浏览器中。
    • 常亮与离线需 https：浏览器仅在 https（或 localhost）下开放 Wake Lock 与 Service Worker；局域网 http 访问时这两项不可用，部署到公网 https 即完整可用。
