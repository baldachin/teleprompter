# 提词器需求说明（已实现，P0 完成）

## 1. 目标

面向 iPhone 的单手提词器，用于自拍视频、直播口播、演讲汇报：脚本大字显示、自动滚动、实时调参、镜像、倒计时、防锁屏、离线可用。

形态：**Web App（PWA）**，零依赖免安装，Safari「添加到主屏幕」后为无地址栏全屏应用。

## 2. 功能清单

| 模块 | 能力 | 状态 |
| --- | --- | --- |
| 入口 | 新建 / 继续上次（带时间戳） / 脚本库 | ✅ |
| 脚本 | 粘贴、导入 `.txt`、示例稿、存为脚本、草稿自动保存 | ✅ |
| 提词 | 自动滚动、当前行高亮、进度百分比、滚到底自动停 | ✅ |
| 实时调参 | 提词中抽屉调字号/行距/边距/语速/主题/镜像/字体/加粗/字距，不中断提词 | ✅ |
| 字体 | 字体下拉（黑体/宋体/楷体/圆体）、加粗开关、字距 0–12px | ✅ |
| 焦点指示 | **按行**高亮：红色半透明底色条 + 左侧三角箭头，阅读线固定在屏幕正中；跨段/空行不回头，镜像下箭头位置不变 | ✅ |
| 配色 | 黑底白字 / 白底黑字 / 黑底黄字 三套预设 | ✅ |
| 边距 | 左右留白百分比 0–18%，可配 | ✅ |
| 速度 | 「字/分钟」（随字号联动换算 px/s）与「像素/秒」两种模式 | ✅ |
| 镜像 | 水平镜像（垂直镜像延后） | ✅ |
| 倒计时 | 0–10 秒 | ✅ |
| 完成态 | 重播 / 回到准备台 / 下一条脚本 | ✅ |
| iPhone 适配 | 竖屏锁定、全屏无地址栏、状态栏沉浸、安全区、禁双击缩放、375px 窄屏无溢出 | ✅ |
| 防锁屏 | Wake Lock，切回前台自动恢复 | ✅ |
| 离线 | Service Worker 缓存 | ✅ |
| 录制 | 摄像头录制 + 脚本叠加 | ⛔ 本期不做 |

## 3. 已知取舍

- 「字/分钟」按中文全角估算每行字数；英文脚本的实际节奏会有偏差，可切到「像素/秒」精调。
- 无摄像头录制能力，需要成片请配合系统相机录制。
- 垂直镜像未实现。

## 4. 本地与真机验证

```bash
node serve.js          # 打印局域网地址
pwsh -File scripts/capture.ps1   # 生成 390×844 移动端截图
```

iPhone 与电脑同一 Wi-Fi，Safari 打开 `http://<局域网IP>:5173` → 分享 → 添加到主屏幕 → 从图标启动。
