## 3. P0 交付内容

### 3.1 一页两态，取代原来的编辑页 / 提词页两段式

```
[准备台] ──开始提词(倒计时)──▶ [提词态] ──滚到底──▶ [完成态]
   ▲                                 │  ▲                  │
   └────────回到准备台────────────────┴──────────────────┘
```

**准备台**
- 顶部三个显性入口：新建 / 继续上次（显示上次时间戳）/ 脚本库
- 脚本区：粘贴、导入 `.txt`、示例稿、存为脚本、草稿自动保存
- 快速设置（可折叠）：主题、字号、行距、边距、速度、镜像、常亮
- 底部固定「开始提词」主按钮

**提词态**
- 顶部 HUD：退出 / 状态与进度 / 设置
- 底部 HUD：暂停·继续 / 慢 / 快
- 点「设置」升起底部抽屉：**字号、边距、语速、主题、镜像实时生效，不中断提词**
- 拖拽文字区任意定位，松手自动续播；轻点显隐 HUD

**完成态**
- 浮层三个动作：重播 / 回到准备台 / 下一条脚本（无后续脚本时禁用）

### 3.2 设置面板单一数据源

设置面板是一份 DOM，在「准备台折叠区」与「提词抽屉」之间移动（`mountSettingsPanel`），
保证任何位置改参数都是同一份状态，不会出现两套控件不同步。

### 3.3 速度单位

- 默认「字 / 分钟」（60–600），按中文全角估算每行字数，随字号联动换算为 px/s：
  `px/s = (字每分 / 60) / 每行字数 × 字号 × 行距`
- 可切换「像素 / 秒」（10–300）做精调，切换时按当前值等价换算，不会跳速。

### 3.4 主题预设

| 主题 | 背景 | 文字 | 高亮 | 适用 |
| --- | --- | --- | --- | --- |
| 黑底白字 | #000 | #f2f2f5 | 红 | 暗光、正式口播 |
| 白底黑字 | #fff | #14141a | 深红 | 室内亮光 |
| 黑底黄字 | #000 | #ffd60a | 橙 | 强光、户外 |

## 4. 本轮修复的缺陷

1. `display:flex` 覆盖 `hidden` 属性 → 帮助抽屉 / 完成浮层 / 倒计时常驻显示。已加全局 `[hidden] { display:none !important; }`。
2. `will-change: transform` 使 `.prompter-lines` 成为 `offsetParent`，高亮坐标错位 → 起始无行高亮。已换算回内容容器坐标。
3. `backdrop-filter` 导致抽屉背景与底层文字混合 → 移除滤镜，改用 `isolation: isolate`。
4. 旧版本 localStorage 缺少新字段导致设置项为 `undefined` → 设置读取改为与默认值合并。

## 5. URL 调试/分享参数

`?text=…` 载入脚本 · `?auto=1` 直接开提 · `?theme=dark|light|yellow` · `?fs=48` 字号 · `?margin=5` 边距 ·
`?speed=300` 语速 · `?cd=0` 倒计时 · `?mirror=1` 镜像 · `?reset=1` 清空本地数据 ·
`?panel=1` / `?sheet=1` / `?finish=1` 展开对应界面（用于截图与演示）。
